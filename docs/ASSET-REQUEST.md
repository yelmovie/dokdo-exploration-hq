# 에셋 생성 요청 목록 (ChatGPT 이미지 생성용 프롬프트)

기존 에셋과 톤을 맞추기 위해 **모든 프롬프트 앞에 공통 스타일 문구**를 붙여서 생성해줘.
생성한 파일은 `assets/` 아래 새 폴더(예: `assets/background2/`)에 넣어 주면 내가 최적화해서 반영할게.

## 공통 스타일 문구 (프롬프트 맨 앞에 복사)

> 밝고 따뜻한 동화풍 디지털 일러스트, 수채화 질감에 또렷한 외곽선, 초등학생용 교육 게임 배경,
> 채도 높은 파랑·초록·금색 팔레트, 글자 없이 그림만, 16:9 가로 비율

## 1순위 — 미션 지도(3p) 해도 배경 ★가장 효과 큼

```
[공통 스타일 문구] + 옛 항해 지도(해도) 스타일의 동해 바다 지도. 왼쪽 아래에 초록 숲이 우거진
울릉도, 오른쪽 위에 동도와 서도로 이루어진 독도. 두 섬 사이 넓은 파란 바다에 은은한 위도·경도선과
물결 무늬, 구석에 고전적인 나침반 장식. 지도 가장자리는 살짝 낡은 양피지 느낌의 테두리.
섬 이름이나 글자는 넣지 말 것.
```
→ 저장: `map_chart.png` (미션 지도 전용 배경으로 교체)

## 2순위 — 발표 준비(9p) 전용 배경 (지금은 2p 교실과 재사용 중)

```
[공통 스타일 문구] + 초등학교 강당의 발표 무대. 무대 위 나무 연단과 마이크,
뒤에는 파란 커튼과 독도 사진이 걸린 대형 스크린, 따뜻한 스포트라이트 조명,
객석은 살짝 흐릿하게. 글자 없는 빈 스크린으로.
```
→ 저장: `bg_presentation.png`

## 3순위 — 수료증 장식 프레임 (수료증 PNG 저장 기능 업그레이드용)

```
[공통 스타일 문구는 빼고] + 상장/수료증용 장식 테두리 프레임, 금색 월계수와 파란 리본,
모서리에 독도 바위섬·괭이갈매기·들꽃 장식, 가운데는 완전히 비어 있는 흰 공간,
투명 배경 PNG, 가로형(가로:세로 = 3:2), 글자 없이.
```
→ 저장: `cert_frame.png` (투명 PNG 필수)

## 4순위 — 탐사본부 브리핑룸(2p) 전용 배경

```
[공통 스타일 문구] + 바닷가 탐사본부 안의 브리핑룸. 대형 코르크 게시판과 동해 지도,
탐사 장비(쌍안경·나침반·무전기)가 놓인 책상, 창밖으로 파란 바다와 독도가 보이는 큰 창문,
밝고 아늑한 분위기. 게시판과 지도에는 글자 없이.
```
→ 저장: `bg_briefing2.png`
