# 독도 탐사본부: 사라진 기록을 복원하라 — 설계 노트

초등 사회 독도교육을 위한 **자료 해석형 탐사 게임 웹앱**.
학생은 탐사대원이 되어 울릉도→독도 항로를 복원하고, 지형·역사·생태의 **근거**를 직접 수집해
브리핑 보드와 발표문을 완성하고 수료증을 받는다.

- 체험: https://dokdo-hq.vercel.app (설치 없음, 태블릿 가로 권장)
- 구성: 10개 씬 · 미션 6종 · 문항 20+ · 도감 카드 15장 · 4개 언어(한/영/중/일)

---

## 1. 설계 원칙 다섯 가지

1. **사실만 쓴다.** 모든 교육 내용은 외교부 독도(dokdo.mofa.go.kr) 자료를 근거로 하고, 출처를 화면에 표기한다. 확인 못 한 것(성취기준 고시 원문)은 "교사 확인 필요"라고 그대로 적는다.
2. **정답을 알려주지 않는다.** 오답이면 그 선택지가 왜 틀렸는지(오개념 피드백)만 주고 재도전. 오답 2회부터는 '단서 다시 보기'를 눌러야 재제출할 수 있다(찍기 방지).
3. **카드 맞히기 금지.** 항로 선긋기, 순서 배열, 드래그 분류, 탭-탭 선연결, 3D 지형 탐험, 발표 녹음 — 조작 자체가 학습 활동이 되게 한다.
4. **배경이 무대다.** UI 패널은 내용 높이만큼만 쓰고(auto+max), 드롭존·카드를 배경 일러스트의 실제 사물(코르크보드 메모지 등) 위에 직접 붙인다.
5. **개인정보는 받지 않는다.** 서버 없음, 기록은 기기(localStorage)에만. 이름은 수료증 출력 후 손글씨로 — 사인처럼.

## 2. 기술 구조 (무빌드 바닐라)

- **바닐라 JS ES 모듈 + 해시 라우터.** 빌드 도구 없음 → 학교 컴퓨터에서도 폴더째 열면 돌아간다.
- **1280×720 고정 스테이지 + fitStage 스케일.** 좌표를 디자인 픽셀로 못 박고 화면 크기에 비율 맞춤 — 전자칠판·태블릿·노트북에서 같은 레이아웃.
- **three.js 로컬 vendor.** 5p 3D 지형 탐사(GLB 디오라마 + 절차적 단면 모형), 10p 전시 모형. Meshy(image-to-3D)로 만든 42MB 원본을 gltf-transform 단순화 + 텍스처 1024 축소로 1.8MB까지.
- **데이터 분리.** 문항·도감·미션은 전부 `src/data/*.js` — 내용 수정에 씬 코드를 건드리지 않는다.
- **에셋 캐시 버전(`?v=n`).** Vercel immutable 캐시가 교체된 에셋(404까지)을 물고 있는 사고 방지.

## 3. 게임 루프

```
브리핑(목표 5) → 미션 지도 → 미션 6종(단서 수집 게이팅 → 활동 → 완료 배지)
→ 근거 카드 → 브리핑 보드 → 발표 준비(녹음) → 수료관(수료증·도감 15장)
```

- 미션마다 **단서 수집이 문제 풀이를 잠금 해제**(게이팅) — 자료를 읽어야 풀 수 있다.
- 모든 미션에 도감 보상 최소 1장. 도감은 5×3 = 15장으로 **그리드를 꽉 채워** 완성감을 만든다.
- 별점·점수 없음 — 비교보다 완주. (재도전 동기는 수집 완성으로)

## 4. 초등 눈높이 인터랙션 — 이번에 배운 것

> 실기기(태블릿) 테스트에서 얻은 교훈. 스킬(touch-check 등)에도 반영함.

- **탭이 기본, 드래그는 보조.** 선연결 활동을 드래그 전용으로 만들었더니 초등 손가락으론 어려웠다. 카드 전체를 탭 대상으로: ① 카드 탭 = 고르기(금색 발광) ② 반대쪽 탭 = 연결. 드래그는 8px 이동부터 판정해 공존.
- **핸들은 눈에는 작게, 손에는 크게.** 연결점 시각 18px / 터치 패드 44px 분리.
- **disabled 버튼은 '고장'으로 느껴진다.** 흐림 처리 + 누르면 이유 안내("카드를 모두 놓은 뒤 눌러요!")로 대체.
- **인앱 브라우저(카카오톡)는 다운로드를 조용히 막는다.** 수료증 저장은 blob 다운로드 + 미리보기(길게 눌러 저장) + Chrome 열기 안내 3중.
- **권한은 앱이 먼저 묻는다.** 마이크는 브라우저 팝업 전에 앱 내 동의 모달(용도·저장 안 함 고지).

## 5. 다국어(한/영/중/일) — DOM 치환 방식

씬 코드를 안 고치고 **렌더된 DOM 텍스트를 사전으로 치환**하는 방식을 택했다(무빌드 유지).

- 사전: 한국어 원문 → 번역 (언어별 800~880키) + 정규식 패턴(조합 문자열용).
- MutationObserver 로 동적 텍스트(토스트·퀴즈 피드백)도 치환, 말풍선은 번역문을 처음부터 타이핑.
- **외교 용어는 파일 전수 스캔으로 강제**: Dokdo/East Sea, 独岛/东海, 独島(ドクト)/東海(トンヘ). 일본식 지명 표기 0건 검증. 태정관 지령은 "일본 스스로 무관하다고 인정"의 방향이 뒤집히지 않게 언어별 대조.
- ⚠️ **함정 하나**: "출력=입력"인 통과형 패턴 + 옵저버 조합은 무한 루프(화면 멈춤)를 만든다. 값이 달라질 때만 기록 + 자기 변경 기록 폐기(takeRecords)로 차단.

## 6. 검증 방법 (사람 손 대신 측정)

- **좌표 실측 스윕**: 전 씬 버튼 잘림·겹침·화면 밖을 getBoundingClientRect 로 전수 측정 (씬 전환 직후는 이중 렌더 오탐 — 1초 대기 후 측정).
- **E2E 재현**: 문제 풀이·드래그·연결을 합성 PointerEvent 로 자동 재현 (드래그는 `buttons:1` 필수).
- **콘솔은 누적**: 리로드 후 새 에러만 판정.
- **배포 확인은 파일로**: 메인 화면 로드만 믿지 말고, 이번 커밋에 포함된 파일을 fetch 해서 최신인지 확인.
- 성적표(10항목×10점)를 날짜별로 남겨 추이 비교 — 측정 못 한 항목은 점수 대신 '측정 불가'.

## 7. 개인정보 설계 (아동 대상)

- 수집 항목: 없음. 진행 기록·학년반번호는 localStorage(기기)에만.
- 수료증: 학년·반·번호는 선택 입력, **이름·학교는 밑줄 칸만 그려서 손글씨로** — 식별 정보 결합(학교+반+이름)이 앱을 거치지 않는다.
- 녹음(발표 연습): 재생용 임시 메모리만, 저장·전송 없음, 모달이 닫히면 마이크 해제.
